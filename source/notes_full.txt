HOW TO UPDATE THIS SLIDE

- Highlight a price: select the cell > Table Design > Shading > pick from the top "Theme Colors" row (red = Price change, green = Bundle & save, purple = BBY+ / Total member deal). On red or purple, also set Font Color to white.
- Remove a highlight: Shading > No Fill, and set Font Color back to the dark default.
- Add a model: click a row > Layout > Insert Above/Below. Delete a row: Layout > Delete > Delete Rows.
